# Demo · Beneficios KPMG × TaquillApp para Empresas

Página única y **100% offline**: abre `index.html` con doble clic en cualquier navegador (no requiere internet ni servidor).

- `index.html` — demo final autocontenida (logo incrustado).
- `src/demo.html` — fuente editable. Catálogo y precios en el arreglo `PRODUCTS` del `<script>`.
- `build.py` — regenera `index.html` tras editar la fuente: `python3 build.py`.
